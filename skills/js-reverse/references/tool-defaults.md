# Tool defaults

- `js-reverse_list_network_requests`: Look at the default results on the first page first, and then turn to the next page if the results are insufficient.
- `js-reverse_search_in_sources`: Default `excludeMinified=true`
- `js-reverse_get_script_source`: Read only small fragments, the entire source code is given priority with `js-reverse_save_script_source`
- `js-reverse_break_on_xhr`: Only fill in URL fragments that can be stably hit
- `js-reverse_get_paused_info`: Look at `frameIndex=0` first by default
